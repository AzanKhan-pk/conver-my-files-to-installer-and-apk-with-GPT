How can we help?

Try these steps first if SaveVido is not working as expected.

Support information · 16 November 2026

Download is stuck

Check your internet connection, confirm the source link is public, and retry. Some websites limit automated requests or temporarily block access.

Audio or high-quality video fails

Some formats require FFmpeg. Make sure the Windows release includes its required media tools or follow the official setup instructions provided with that release.

Installer warning appears

Only install packages linked from the official SaveVido website. Check the publisher and digital signature where available. Do not bypass security warnings for an unverified file.

Report a bug

Include your SaveVido version, Windows or Android version, the action that failed and the exact error message. Do not send passwords, private cookies or personal account information. A public support email has not yet been configured; use the in-app feedback option if available.
