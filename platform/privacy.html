YOUR DATA

Privacy Policy.

This notice explains what the SaveVido website and Windows desktop application do with information.

Effective date: 19 November 2026 · Last updated: 19 November 2026

1. Information collected by the website

The public website does not connect directly to the analytics database and does not receive database credentials. Only after you select Allow analytics in the website consent notice does the browser send a limited page-view event to SaveVido's separate analytics service. You can select Decline. A random browser session identifier is transformed into a SHA-256 hash before storage. The service may derive approximate country and city from hosting request metadata; it does not use GPS or provide a live location. You can clear this site's local storage to reset your analytics choice.

2. Windows desktop application analytics

On first launch, the Windows desktop app asks whether you want to share anonymous app-open events, app version, download success/failure events, file type and the source website hostname. Choosing No disables this telemetry. The app does not send the full media URL, query parameters, downloaded file, file name or raw IP address. The analytics service may infer approximate country/city from the incoming network request. This is approximate network metadata, not GPS location or live tracking. This choice is stored locally in the SaveVido app-data folder.

3. Feedback and optional one-time location

When you submit feedback, SaveVido stores the nickname, message and at least one contact method (email or WhatsApp) in its private Neon database so the owner can review and respond. If you use the support-note shortcut, the report can also include the source media URL, app/site name and error details. The app removes URL fragments and most query parameters before storing a source URL.

Location sharing is optional. If you check the location-sharing box on the feedback form and submit it, the browser asks for permission. Only after permission is granted, the one-time coordinates, reported accuracy and timestamp are sent with that feedback and shown in the owner-only dashboard. SaveVido does not continuously track location, run background GPS, or collect a live 24/7 location feed. If you deny permission or leave the box unchecked, no precise location is stored and you can still send feedback and use the app.

4. Analytics and hosting providers

Website analytics are processed using Neon PostgreSQL and the website is hosted by Vercel. These providers may process technical connection data, such as IP addresses and request metadata, as part of providing and securing their services under their own policies. SaveVido's analytics tables are designed not to store raw IP addresses.

5. Information handled locally by the desktop app

The Windows application processes the media URL you enter so it can request information from the source website. Download history, job state, settings and file paths may be stored locally on your device. Downloaded files are saved to the folder shown in the app. Do not enter passwords or share private account cookies with the app.

6. Third-party websites

When you provide a link, the app may communicate with the linked service or its content-delivery providers. Those services operate under their own privacy policies and terms. SaveVido does not control their data practices.

7. Why information is used

  • To operate and secure the website and application.
  • To understand aggregate website usage and service reliability when analytics is enabled.
  • To save local download history, preferences and resumable job information.
  • To diagnose errors and improve supported functionality.

8. Retention and security

Analytics data is intended to be retained for up to 90 days. Feedback records, including any location voluntarily shared with a report, are retained for support and troubleshooting and can be reviewed only through the owner dashboard and server-side API. Database credentials are not sent to the public website or desktop app. Reasonable technical safeguards are used, but no internet service or local device can be guaranteed completely secure. You may request correction or deletion of a feedback record through a follow-up feedback message.

9. Your choices

You can decline website or desktop analytics. You can leave the feedback location box unchecked or deny the browser's location prompt. You can clear this website's local storage to reset its local session identifier. You can remove local app history or files using the app and your device's file manager; deleting a history entry may not delete the downloaded file itself. You can also disable location access in your browser or Windows privacy settings.

10. Children and sensitive information

Do not use SaveVido to access age-restricted material or submit sensitive personal information. Users under the age of majority should involve a parent or guardian when sharing personal contact or location information with online services.

11. Private owner dashboard

Feedback submissions and any voluntarily shared one-time location are visible only to the service owner through the private dashboard. Feedback is not an account or sign-in registration; there is no user password or OTP for this form. Anonymous analytics sessions are not treated as verified identities.

12. Changes and contact

This policy may be updated as features change. The current version will be posted here. A dedicated public privacy contact address has not yet been published; use the in-app feedback option if available.
